Сравнимое.
Создайте ссылочный тип Сравнимое, гарантирующий наличие по данной ссылке

Функция.

3. Типы T и P выводятся компилятором автоматически из переданных аргументов (автовывод типа).
4. В Main4 продемонстрировать три случая: список строк в список длин (T и P не совпадают), список чисел в список модулей (T и P совпадают), список массивов int в список максимумов каждого массива (лямбда с циклом поиска максимума).

Задача 3
Текст задачи:
Сокращение.
Разработайте метод, который будет принимать список значений типа T и способ,
с помощью которого список значений можно свести к одному значению типа T,
которое и возвращается из метода. Демонстрация: склеивание строк; сумма
чисел; общее количество элементов во всех подсписках. Далее измените метод
так, чтобы он гарантированно не возвращал null и не выбрасывал ошибок, если
исходный список пуст.
Алгоритм решения:
1. Создать функциональный интерфейс Reducer<T> с единственным методом T reduce(T current, T item).
2. В GenericOps разработать обобщенный метод <T> T reduce(List<T> source, Reducer<T> reducer, T emptyValue): начальное значение результата - emptyValue, затем цикл по списку последовательно сворачивает элементы.
3. Параметр emptyValue и есть требуемая модификация: на пустом списке метод возвращает значение по умолчанию, гарантированно не возвращает null и не бросает исключение.
4. В Main4 продемонстрировать: склейку строк (emptyValue - пустая строка), сумму чисел (emptyValue - 0), подсчет общего числа элементов через последовательное применение map (списки в их размеры) и reduce (размеры в сумму), а также явный вызов reduce на пустом списке.

Задача 4
Текст задачи:
Коллекционирование.
Разработайте метод, который будет возвращать коллекцию типа P со значениями
типа T. Метод принимает: список исходных значений; способ создания
результирующей коллекции; способ передачи значений исходного списка в
результирующую коллекцию. Демонстрация: разбиение чисел на положительные и
отрицательные подсписки; группировка строк по длине; набор без дубликатов.
Алгоритм решения:
1. Создать функциональные интерфейсы Creator<P> с методом P create() (способ создания результирующей коллекции) и Adder<P, T> с методом void add(P target, T value) (способ передачи значения).
2. В GenericOps разработать обобщенный метод <T, P> P collect(List<T> source, Creator<P> creator, Adder<P, T> adder): результат создается вызовом creator.create(), затем каждый элемент исходного списка передается в него вызовом adder.add.
3. Демонстрация 1: P - List<List<Integer>>, creator создает два подсписка, adder распределяет числа в положительные и отрицательные.
4. Демонстрация 2: P - List<List<String>>, adder ищет подсписок строк той же длины и добавляет строку в него, а при отсутствии такого подсписка создает новый.
5. Демонстрация 3: P - HashSet<String>, коллекция, не способная содержать одинаковые объекты; дубликаты отсеиваются самим множеством.
